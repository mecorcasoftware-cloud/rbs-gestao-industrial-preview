# RBS Gestão Industrial — Prévia

Modelo público de apresentação do sistema RBS Gestão Industrial.

A prévia demonstra a organização visual dos módulos de visão geral, orçamentos de peças usinadas, manutenção, produção, relatórios, máquinas e materiais e peças.

## Acesso

Abra `index.html` para visualizar a tela inicial. O botão de orçamento utiliza `calculator.html`, que deve permanecer na mesma pasta.

## Importante

Este repositório contém uma prévia estática com dados demonstrativos. Não contém autenticação real, conexão com Supabase, usuários reais, permissões reais ou dados de clientes. A implementação de produção deverá seguir o documento `DIRETRIZES-E-ACESSOS.md`.
